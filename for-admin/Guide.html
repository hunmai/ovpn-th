OpenVPN App Verification Guide

คู่มือติดตั้งสคริปต์ Python ตรวจสอบ Package Name ของแอปพลิเคชัน

Python 3 Script

ภาพรวมระบบ

หน้านี้รวบรวมขั้นตอนการติดตั้งสคริปต์ Python สำหรับตรวจสอบสิทธิ์การเชื่อมต่อ OpenVPN โดยจะอนุญาตเฉพาะแอปพลิเคชันที่มีแพ็กเกจตรงกับที่กำหนดไว้เท่านั้น คุณสามารถคลิกปุ่ม "คัดลอก" เพื่อนำคำสั่งไปใช้งานบน Server ได้ทันที

1.1

สร้างโฟลเดอร์เก็บสคริปต์

พิมพ์คำสั่งนี้เพื่อสร้างโฟลเดอร์สำหรับเก็บสคริปต์ตรวจสอบ:

mkdir -p /etc/openvpn/scripts
1.2

สร้างและเขียนโค้ดไฟล์สคริปต์

พิมพ์คำสั่งเพื่อสร้างไฟล์ชื่อ check_gui.py ด้วยโปรแกรม nano:

nano /etc/openvpn/scripts/check_gui.py

เมื่อหน้าต่างว่างๆ เปิดขึ้นมา ให้คัดลอกโค้ดด้านล่างนี้ไปวางทั้งหมด:

#!/usr/bin/env python3
import os
import sys

def main():
    # ดึงข้อมูลการเชื่อมต่อที่ OpenVPN ส่งมาให้
    common_name = os.environ.get('common_name', 'Unknown')
    iv_plat = os.environ.get('IV_PLAT', 'Unknown')
    iv_gui_ver = os.environ.get('IV_GUI_VER', 'Unknown') 
    
    print(f"[VPN-AUTH] User: {common_name} | Platform: {iv_plat} | Client Info: {iv_gui_ver}")

    # รายชื่อ Package Name ของแอปทั้งหมดที่คุณอนุญาต (เพิ่ม 2 แอปใหม่เข้ามาแล้ว)
    allowed_packages = [
        "com.pukangvpn.th",
        "com.khamvpn.net",
        "com.shanvpn.vpnth",
        "com.shanvpnpro.net"
    ]
    
    # ตรวจสอบว่าในข้อมูลที่แอปส่งมา มีชื่อแพ็กเกจของเราอยู่หรือไม่
    is_allowed = False
    for pkg in allowed_packages:
        if pkg in iv_gui_ver:
            is_allowed = True
            break
    
    # ถ้าไม่มีแพ็กเกจไหนตรงเลย (เช่น ไปเปิดจากแอปอื่น) -> ตัดการเชื่อมต่อทันที
    if not is_allowed:
        print(f"[REJECT] Unauthorized app detected: {iv_gui_ver}")
        sys.exit(1) # ส่งค่า 1 เพื่อปฏิเสธการเชื่อมต่อ

    # ถ้าถูกต้อง (มาจากแอปของเรา) -> อนุญาตให้เชื่อมต่อปกติ
    print("[ALLOW] Connection accepted from official app.")
    sys.exit(0) # ส่งค่า 0 เพื่อให้อนุญาต

if __name__ == '__main__':
    main()
1.3

ให้สิทธิ์ตัวไฟล์สคริปต์ให้สามารถรันได้

พิมพ์คำสั่งนี้เพื่อให้ระบบยอมรับไฟล์สคริปต์:

chmod +x /etc/openvpn/scripts/check_gui.py
1.4

บอก OpenVPN Server ให้เรียกใช้สคริปต์นี้

เปิดไฟล์ตั้งค่าหลักของเซิร์ฟเวอร์ขึ้นมาแก้ไข:

nano /etc/openvpn/server.conf
หมายเหตุ: หากไฟล์เซิร์ฟเวอร์ของคุณเก็บไว้ที่อื่น เช่น /etc/openvpn/server/server.conf ให้เปลี่ยนไปใช้พาธนั้นแทนครับ

เลื่อนลงไปที่บรรทัดล่างสุดของไฟล์ แล้วเพิ่ม 2 บรรทัดนี้ลงไป:

client-connect /etc/openvpn/scripts/check_gui.py
script-security 2
1.5

รีสตาร์ท OpenVPN เพื่อเปิดใช้งานระบบ

พิมพ์คำสั่งรีสตาร์ทเซอร์วิส OpenVPN (ชื่ออาจแตกต่างกันตามเซิร์ฟเวอร์ของคุณ เช่น openvpn@server):

systemctl restart openvpn@server
